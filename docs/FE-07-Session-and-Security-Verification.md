# FE-07 — Session và security verification

Giữ một useSession trong App và shared requestApi/CSRF helper. Không second provider/client, JWT, secret storage hoặc hardcoded role/session.

- unknown không render private DTO; auth/me200 mới authenticated,401 initial→guest, confirmed session bị401→expired, lỗi dịch vụ→error. Protected guest/expired→Login với safe return, sessionerror giữ error/retry phù hợp, không fake404/Home redirect.
- refresh loại identity/draft trước xác minh; generation/controller chặn old auth response. Transition refresh + BroadcastChannel chỉ gửi chuỗi changed, không user/token. Tab khác nhận event thì refresh và drop private subtree; khi BroadcastChannel thiếu, reload/private401 vẫn Backend-authoritative. Không polling/realtime claim trên mọi browser.
- Login request success không tự dùng DTO role để khẳng định phiên; auth/me xác nhận. Register không tự đăng nhập. Profile/preferences saved chỉ sau200, sau đó đọc session mới. Reset/change/logout refresh đúng policy.
- Logout POST204 revoke current session thật; HttpOnly cookie do Backend clear. Failure/uncertain conceal private state và GET auth/me để reconcile; không “Đã đăng xuất” nếu không confirmed. ACC-E05 cho server thực hiện logout rồi drop response, xác nhận một write, private UI bị loại, feedback uncertain.
- Change/reset atomic authVersion invalidates ALL sessions/outstanding tokens; current cookie cleared. UI yêu cầu Login lại, không rotation hay reuse session giả. Current password wrong INVALID_CREDENTIALS không bị client nhầm thành global expiry.
- Cookie HttpOnly/Path=/SameSiteLax, Secure/__Host khi HTTPS theo Backend config giữ nguyên. Không đọc cookie bằng JS, không lưu password/session/CSRF/reset/verify token trong storage/URL query/log. Client chỉ memory CSRF, refresh/invalidate sau transitions.
- GET không attach CSRF; login/register/logout/mail/profile/password/settings mutations dùng X-CSRF-Token và credentials include. Backend origin/session checks giữ nguyên. Real missing CSRF được test qua Browser→Backend403; expired/invalid/concurrency/rotation có Backend integration và client unit regression.
- Safe return chỉ implemented public/account paths; external/protocol-relative/backslash/control/double-encoded/query secrets/auth loops bị loại. Không replay mutation sau login. Role/access UI là UX, Backend vẫn kiểm tra active account/ownership/authVersion từng API.

Security evidence: ACC-E01 sessions/cookie/reload/change/logout, E02 verification/reset/one-use, E04 CSRF rejection + two identities/two tabs + expiry, E05 double submit/uncertain logout, E06 unavailable provider; ACC-U01..15 + foundation regression; Backend AUTH integration chạy mới. Ở E04 chỉ expiry timestamps của test-owned records bị chỉnh sau valid journey để tạo negative case, không tạo session/token giả hoặc bypass email path để báo completion.

Giới hạn: token trần chỉ tồn tại trong email capture memory cho test và component memory cho explicit flow; không commit artifacts chứa token/password. Capture transport chứng minh local email-contract journey, không Gmail/TLS network delivery hoặc absolute security. Session/tab synchronization mới chỉ browser cases được chạy; không cross-device revoke UI vì thiếu endpoint. Avatar/media/Admin không mở rộng.
