# FE-08 — Recipe Editor

Source: frontend/src/features/editor/model.js và screens.js. Dùng React/createElement, existing tokens/KitchenShell, shared requestApi/useRead/session. Không dependency/editor framework/API client/Auth owner thứ hai.

Form chia thông tin, danh mục/độ khó/thời gian/khẩu phần/nhãn, nguyên liệu, bước nấu, ảnh fallback và thao tác. Không dùng rich text hoặc unsafe HTML. Description/instruction là input một dòng theo validator Recipe; không áp policy multiline Bio. Dữ liệu raw được giữ khi chỉnh sửa/lỗi, không âm thầm strip ký tự; Backend normalize NFC/trim/tag lower-dedupe khi lưu. Chi tiết bounds tại [Contract audit](FE-08-Recipe-and-Media-Contract-Audit.md). Draft không bắt buộc title/category/time/ingredients/steps. Publish có validation riêng.

Ingredients optional canonical ID (catalog active), bắt buộc name cho mỗi row đã thêm. Free-text hợp lệ. Search debounce250ms, tối đa20 kết quả mỗi prefix, refine search để tìm cụ thể; không cursor/total giả. Danh mục dùng useCategoryOptions tải thêm từng page100 theo yêu cầu. Current inactive/unavailable ID được giữ bằng option context, không bịa tên hoặc chấp nhận inactive mới. Quantity0 bảo toàn, rỗng→null; unit/quantityText/note theo whitelist. Không gửi key nội bộ/owner/status/moderation/totalMinutes.

Rows có local UUID stable React key; reorder giữ giá trị và identity. Button Up/Down không drag library; Remove không xóa row khác; Add/Remove/Reorder announce/focus. Ingredients≤40,steps≤30. Serialize full arrays và order1..N. Step mới omit stepId, Backend cấp; step đã lưu giữ stepId và imageAssetId. Existing cover reference được giữ; không hiện attach/remove image UI khi delivery chưa đủ.

State: loading owner GET→ready; change→dirty; submit→validate→saving; exact HTTP201/200 + checked OwnerRecipeDTO→saved. Validation error focus firstinvalid hoặc summary, giữ input. Server422 details map theo field path; lỗi không đưa raw server message/stack vào DOM.429 có cooldown Retry-After.403/401/404 có thông báo; CSRF_INVALID khóa write đến reload. Không autosave/automatic mutation retry hoặc sensitive localStorage.

PATCH gửi version của snapshot đã tải/confirmed save.409 chuyển conflict: giữ local fields, khóa write; explicit GET đối chiếu bản server trong section có status/version và details JSON safe text. Người dùng xác nhận bỏ local rồi nhận server snapshot mới; không tự ghép/overwrite hoặc nâng version rồi gửi lại fields cũ. Uncertain write (network/timeout/5xx/unexpected202/DTO mismatch) khóa write, GET đối chiếu cho known ID. Không tuyên bố cancel request đồng nghĩa rollback. DELETE uncertain có thể GET404; người dùng kiểm tra list, không fake delete success.

Dirty navigation: router guard native confirm Stay/Leave; browser Back/Forward qua popstate guard; hard reload/close có beforeunload. Native prompt text do browser quyết định. Khi cancel Back, router khôi phục URL bằng pushState (giới hạn: history forward branch có thể bị thay). Không cung cấp full history-stack fidelity claim. Sau saved không cảnh báo. Khi identity revision/route đổi private subtree unmount, abort GET/write và bỏ local form/key; generation/active guard loại late results. Session transition không giữ draft user A dưới user B. No background GET ghi đè dirty local values.

Published chỉ đọc; không Save/Edit/Delete, không tự unpublish. Publication confirmations là inline section (không modal): heading focus, nút Xác nhận/Hủy keyboard-accessible; không cần modal trap/inert. Có review trước hành động phá hủy, không xóa ngay lần đầu.
