Operation names list/get checked against current OpenAPI in final inventory; source paths are authoritative. No separate ingredient/step endpoints: full arrays PATCH, order1..N; new steps OMIT stepId; returned IDs retained. Optional canonical ingredientId, free-text name valid. Catalog public APIs active-only; retain current unavailable reference without inventing label.

Draft accepts empty object/title; defaults arrays empty, numeric null, status draft/version0. Plain text rejects <> and Unicode Cc/Cf INCLUDING newline/tab BEFORE NFC trim. title150/description2000/tag40×12/name100/unit32/quantityText100/note500/instruction2000; quantities0..1e9 nullable; minutes integer0..1440 nullable; servings1..100 nullable; ingredients40/steps30. UI preserves raw edits, explains rejection; server normalizes NFC/trim/tags lower-dedupe after validation.

Publish: title≥3,description≥10,active category,difficulty,servings,prep/cook (zero valid),≥1 ingredient with quantity (zero valid) OR quantityText,≥1 step instruction≥5; sequential order and server stepId; normal moderation; stable media references if any. Cover image NOT required. Version increments on updates/transitions. Published is read-only; explicit unpublish before edit/delete. Hidden cannot publish.
