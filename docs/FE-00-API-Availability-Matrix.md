## Contract cần giữ khi tích hợp

- User ID là `id`; Recipe ID là `recipeId`, detail public dùng slug, owner/social dùng ObjectId. Public card không có provider IDs, ratingSummary, isFavorited; avatarUrl/coverImageUrl/imageUrl hiện null.
- Search q exact folded words AND trên title/description, không phải full-text tìm tên nguyên liệu. Lọc nguyên liệu qua ingredientIds CSV + ingredientMatch any/all. Không tự map “Ít nguyên liệu” hoặc dietary claim thành filter chưa có; “Món nhanh” cần chốt maxMinutes tại FE-01/03.
- List public chỉ published+normal+undeleted+active author+creation complete trước count/page. Hidden/private404; Admin không bypass public visibility.
- Review GET summary live; own review PUT201/200, DELETE204 tombstone, không self-review; hidden tombstone409. Comment POST201 UUID key, PATCH version; reply1cấp; parent hidden/deleted suppress replies.
- Admin report list trả context và version cần xử lý, không có GET report detail riêng. Moderation receipt là quyết định lịch sử; refresh list/current state sau mutation. MODERATION_UNCERTAIN503 retry cùng key; MODERATION_PENDING409 không tự đổi key để bypass.
- CSRF GET /api/v1/auth/csrf trả data.csrfToken; cookie HttpOnly; X-CSRF-Token cho writes. Session-bound CSRF đổi sau login/logout/password reset/change. Không retry mutation vô hạn hoặc tạo key mới cho cùng uncertain request.
- API lỗi `{success:false,error:{code,message,details?},requestId}`; 204 không parse JSON. Validation body thường422, query/params400; lỗi field cần đọc shape thực, không đoán string.
- Private cache phải xóa khi logout/session expiry, safe return path chỉ nội bộ; không role/session/token localStorage. Media Idempotency-Key cũng bắt buộc và giữ cùng bytes/purpose khi retry.

Evidence: routes auth/users/catalog/recipes/favorites/media/social; config/security, DTO/validators và tests tương ứng; FE-00-report ghi lệnh/count và lỗi baseline ban đầu.
