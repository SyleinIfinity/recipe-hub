# BE-06.5 — OpenAPI & Swagger developer guide

Nguồn đặc tả duy nhất: `backend/src/openapi/openapi.yaml` (OpenAPI 3.1.0). JSON runtime chỉ điều chỉnh tên cookie từ security configuration thực tế. 46 paths, 53 operations, 51 schemas cho BE-00..13 (social interactions và audited moderation); không chứa endpoint planned. Version đặc tả `0.13.0` là mốc tài liệu, repository chưa khai báo package version.

## Bật docs local

Trong `backend/.env` local, cấu hình `APP_DOCS_ENABLED=true`. Thêm origin backend mà bạn mở vào danh sách `APP_ORIGINS` hiện có, ví dụ `http://127.0.0.1:3000` hoặc `http://localhost:3000`. Giữ nguyên các origin frontend cần dùng. Không dùng wildcard. `.env.example` đã có ví dụ local; không chép đè `.env` đang có credential.

Từ repo `source/`, chạy `npm run dev:api`. Mở `http://127.0.0.1:3000/api/docs`; JSON tại `/api/openapi.json`. Nếu đổi PORT/HOST thì dùng origin tương ứng. Không cần sửa frontend/Vite. Backend vẫn cần MongoDB readiness theo Foundation.

`APP_DOCS_ENABLED` mặc định false ở mọi môi trường, chỉ nhận chuỗi `true`/`false`. Production từ chối cấu hình true; application factory cũng chặn docs nếu NODE_ENV=production. Khi disabled, UI, assets và JSON đều 404. Muốn docs production cần một Work Order riêng chốt access control.

## Manual Try it out với cookie và CSRF

1. Trong nhóm Auth, mở `GET /api/v1/auth/csrf`, chọn **Try it out → Execute**.
2. Copy `data.csrfToken` từ response. Đây là CSRF token, không phải session token.
3. Mở `POST /api/v1/auth/login`; nhập token vào **X-CSRF-Token**, điền email/password tài khoản thử nghiệm của bạn, Execute.
4. Sau login 200, chạy **GET csrf lại**. Token trước login không hợp lệ với session mới.
5. Với token mới, thử `PATCH /api/v1/me/profile` với `{"bio":"Hồ sơ thử nghiệm"}`. Browser tự gửi cookie HttpOnly cùng origin.
6. Admin có thể dùng `POST /api/v1/admin/categories` hoặc ingredients. User thường nhận 403; không có public endpoint cấp admin. Chỉ dùng fixture DB test hoặc tài khoản admin đã được cho phép.
7. Sau logout/change/reset password, đăng nhập lại và lấy CSRF mới. Không lưu token vào localStorage hoặc chia sẻ ảnh chụp chứa token/cookie.

Không có ô Authorize nhập raw cookie; cookie vẫn được mô tả trong security scheme. Không có interceptor tự làm CSRF; quy trình manual được test bằng Firefox. Nếu 403, kiểm tra origin chính xác và lấy lại CSRF, không tắt middleware.

Request schemas hiển thị whitelist/giới hạn. Response examples/schema mô tả envelope; 204 không body. Query/ID sai trả 400; body sai trả 422; thiếu phiên 401 khi CSRF hợp lệ; thiếu quyền/CSRF 403. Lỗi DB là 500 generic. AdminUserDTO không có preferences. Avatar khác null hiện trả 422 MEDIA_NOT_AVAILABLE. Category GET có meta page/limit, ingredient GET không có meta. Catalog search giữ dấu, prefix literal, không fuzzy.

Các giới hạn text ghi rõ sau trim/NFC/whitespace normalization; JSON Schema mô tả giá trị canonical, không thực thi biến đổi Zod. Uniqueness, timezone runtime và state/permission rules còn cần service/integration tests. Không khẳng định validator OAS thay thế mọi business rule.

Email operations đã có code nhưng có thể gửi thư thật khi SMTP bật; không thử khi chưa được phép. Suite dùng fake/disabled provider. Gmail live chưa được nghiệm thu. Register không tự login.

## Validation, CI và cập nhật BE-07 trở đi

- `npm run openapi:validate`: parse YAML, validate OAS 3.1 offline, local refs, operationId, security/CSRF, 204, DTO fields và parity route/spec/Markdown.
- `npm run test:unit`: kiểm tra validator, các mẫu boundary so với Zod, defaults/prod gate và deliberate drift failures.
- `npm run test:integration`: MongoDB test riêng, kiểm tra response của 38 operations bằng JSON Schema, cookie/CSRF/quyền, expiry, UI/spec exposure.
- `npm run test:e2e`: Firefox Foundation và Swagger thực; test fixture riêng trong recipe-hub-test, không gọi provider thật.
- `npm run check`: lint, format, OpenAPI validation, unit/integration, build. GitHub Actions đã gọi check và E2E; remote CI vẫn chưa xác minh.

Mỗi Work Order thêm/sửa API phải cập nhật YAML, bảng inventory trên, Markdown module, RTM, tests trong cùng thay đổi. BE-07 adapter-only không thêm media endpoint. BE-08 trở đi chỉ thêm operation khi route và tests đã có. Không đưa spec lên Swagger Editor/validator bên ngoài.

Route checker dùng route factories thật và kiểm tra mount map trên Express 5 app stack. Router mới/đổi mount hoặc method/path bị thiếu khiến gate fail; khi upgrade Express phải kiểm chứng lại internal Layer matcher. Middleware động và semantic rules không được coi là tự động phủ 100%. Suite real HTTP và Firefox bổ sung evidence cho inventory.

Swagger UI assets cục bộ, validatorUrl=null, queryConfigEnabled=false, không telemetry mạng của ứng dụng. CSP chỉ tại docs: script self, connect self; inline style cho Swagger, không inline script/unsafe-eval. Helmet toàn app giữ nguyên. Cả UI và JSON có Cache-Control no-store. Không cần cloud credentials.
