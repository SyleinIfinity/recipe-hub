# FE-05 — API và security foundation

Client duy nhất vẫn `services/api.js`. `readApi` tương thích các public GET cũ; `requestApi` bổ sung method/body, JSON/FormData, signal và timeout8s. Same-origin base mặc định `/api/v1`, Vite proxy `/api` giữ nguyên; configured external base bị từ chối để không chuyển credentials/CSRF sang origin khác. `credentials:include`, Accept JSON; multipart để browser tự đặt boundary.

200/201 giữ server DTO/resource ID; envelope thêm `http.status` và `http.accepted` (202 chỉ accepted, không chứng minh hoàn thành/delivery). 204/205 trả null, không parse body. Client này dành JSON envelope; non-JSON/HTML được từ chối an toàn, không tự coi là dữ liệu JSON. Binary media dùng image URL policy hiện hành; chưa có binary-fetch/upload UI trong FE-05.

`ApiError` giữ status/code, method và path không query/body, validation field/code đã lọc, Retry-After seconds/date, uncertain flag. Không giữ Backend message/stack/raw body/headers. 401 UNAUTHENTICATED invalidates identity; INVALID_CREDENTIALS giữ form/session; 403 CSRF_INVALID invalidates CSRF, khác FORBIDDEN. 409/413/415/422/429/500/503 vẫn giữ status/code để feature xử lý riêng. ErrorState có thông báo theo ngữ cảnh 400/401/403/409/429/uncertain, không Toast chung. Form inline 422/file flows thuộc Work Order sau.

AbortController cleanup đúng lifecycle; timer kết thúc sau khi đọc body. Timeout/network/abort sau dispatch mutation được đánh dấu outcome uncertain; 5xx cũng bảo thủ coi uncertain. Không automatic retry bất kỳ mutation nào. CSRF invalid không replay. Hủy UI không chứng minh server hủy write. Signal pre-aborted không dispatch; nếu đang chờ CSRF thì helper có timeout8s riêng trước khi dispatch mutation. Caller cần reconcile server state trước gửi lại nếu uncertain.

Backend source `config/security.js` và OpenAPI `getCsrf` xác nhận GET `/auth/csrf`, `data.csrfToken`, header `X-CSRF-Token`, cookie HttpOnly browser/session-bound. Token chỉ memory, retrieval đồng thời dùng chung promise; cache55phút nhỏ hơn cookie1giờ. Public GET không thêm CSRF. Refresh/invalidate xóa token/pending; epoch chặn token cũ hoàn tất sau transition. FE-07 phải gọi `session.refresh()` sau login/logout/password/reset; hàm xóa identity cũ trước khi GET auth/me xác nhận phiên mới. Không đọc HttpOnly cookie, localStorage/sessionStorage hay log token. Không thử live mutation/provider để kiểm tra helper.

`useSession` là owner duy nhất trong App: unknown→authenticated/guest/error; confirmed auth gặp unauthorized→expired. `revision` loại subtree/draft cũ khi transition; refresh/unmount abort request, generation chặn old auth response. Adapter `auth` giữ nguyên Home/Shell presentation. Chưa có auth pages nên chưa expose navigation protected.

Future private hooks dùng `useRead(path, reload, { privateRequest:true, revision:session.revision })` và chỉ mount khi session authenticated. Client `contextSensitive` từ chối kết quả của epoch cũ; hook gắn path/reload/revision và active guard. Không cache private DTO toàn cục. Old401 từ epoch cũ không được làm hết phiên mới. Public hooks vẫn hoạt động khi auth/me trả401.

`useRead.phase` phân biệt loading/ready/empty/error/unavailable/unauthorized/forbidden/stale, null path là idle/initial qua asyncPhase. Stale path/reload/revision không được render dưới URL/context mới. Network errors xử lý tại data/features; render errors qua ErrorBoundary root và feature (key route/query/revision), fallback dùng existing Kitchen panel/button và reload/native Home link. Boundary không bắt event/async errors và không được dùng thay client error handling.

Tests dùng controlled fetch xác minh headers, invalidation, no replay, timeout/abort, status/media/envelope và session races; public browser journeys vẫn dùng Backend/Mongo thật. Không sửa Backend/security contract.
