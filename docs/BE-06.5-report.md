## D. OpenAPI Implementation

OAS **3.1.0**, version tài liệu **0.6.5** (repo chưa có package version). Inventory 25 operations: Health 3; Auth 10; Users 6; Categories 3; Ingredients 3. GET/PATCH preferences chung path nên tổng 24 paths.

Nguồn YAML duy nhất. Runtime JSON chỉ thay tên cookie từ `identity.security.sessionCookie`; HTTPS dùng __Host- prefix. Không generate spec thứ hai để maintain. Refs nội bộ, không external resolver/network. Parser xác minh OAS 3.1 và refs; checks operationId/method-path, security/CSRF, 204, strict body và DTO fields. Request schemas canonical ghi rõ normalization và business constraints chưa thể biểu diễn hoàn toàn bằng JSON Schema.

Route inventory đọc route factories thật, xác minh mount map bằng app stack Express 5. New router/mount không biết bị fail; không suy đoán regex mount. Kiểm tra Markdown inventory bằng markers. Integration app thật so route inventory và validate response JSON của **tất cả 25 operations** bằng Ajv 2020. Không claim kiểm chứng mọi semantic rule bằng schema hoặc tự động extract được mọi middleware động.

Implementation differences được giữ chính xác: AdminUserDTO không preferences; avatar non-null 422; change-password POST; Category meta chỉ page/limit; Ingredient không meta; query/params invalid 400, body invalid 422; catalog prefix giữ dấu. Planned Media/Recipe/P2 không có trong live spec.

## F. Security

Giữ nguyên session HttpOnly, server-side token hash, CSRF và role middleware. Firefox đăng ký/login qua Swagger; browser nhận HttpOnly cookie. Token trước login bị 403; token mới PATCH profile 200; user POST category 403; admin fixture DB test POST category 201. Integration thêm missing/wrong CSRF 403, guest với CSRF hợp lệ 401, expired session 401, protected fields 422. Không cấp Admin production/development.

Spec không có passwordHash/authVersion/tokenHash/lookupKeys/normalizedName hoặc raw session examples. Examples dùng tài khoản example.test và dữ liệu giả. CSRF response được mô tả vì là API public cần thiết, không hardcode token thật. Không đọc/ghi credential qua Swagger, không gọi SMTP/Cloudinary trong tests. `.env` vẫn ignored và không bị sửa.
